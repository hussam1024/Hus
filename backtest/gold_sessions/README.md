# اختبار جلسات الذهب

السكربتات التي أنتجت أرقام `Gold_Session_Edge.pine`. تحتاج ملفات `PAXGUSDT-1m-*.zip` (سبوت) و `XAUUSDT-1m-*.zip` (عقود) من `data.binance.vision` في مجلد `gold` بجانب مجلد السكربتات.

- `g.py`: تحميل البيانات.
- `s1.py` و `s1b.py` و `s1c.py`: متوسط الحركة بكل ساعة، واكتشاف خلل قياس «الافتتاح إلى الإغلاق» على PAXG، ومقارنة PAXG بعقد XAUUSDT.
- `s2.py`: انحياز الجلسات سنة بسنة وأثر عطلة نهاية الأسبوع.
- `s3.py` و `s4.py`: بطارية الفرضيات الهيكلية (اكتشاف 2020–2023، تأكيد 2024–2026).
- `s5.py`: محاكاة الصفقتين على بيانات الدقيقة مع التكاليف والوقف والهدف.
- `s6.py`: النتيجة المجمّعة بوحدة R شهرًا بشهر، وحساسية توقيت الصفقة F.
- `s7.py`: الحساسية لتأخير الدخول واتساع السبريد.
