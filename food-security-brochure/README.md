# مطوية قطاع الأمن الغذائي وسبل العيش (FSL) – منتدى الإغاثة والبناء CRB

مطوية ثلاثية بحجم **A4 أفقي (297×210 مم)**، مستخرجة من تقرير «حصاد 10 سنوات 2016–2025».

## الملفات الجاهزة (`output/`)
| الملف | الاستخدام |
|---|---|
| `CRB-FSL-Brochure-A4.pdf` | صفحتان (خارجي + داخلي) بالمقاس النهائي – للعرض والطباعة المكتبية |
| `CRB-FSL-Brochure-PRINT-bleed3mm.pdf` | نسخة المطبعة: نزف 3 مم + علامات القص + علامات الطي (متقطعة) |
| `CRB-FSL-Brochure-outside.png` / `-inside.png` | معاينة 300dpi لكل وجه |

## توزيع اللوحات (طيّ عربي يفتح من اليسار)
**الوجه الخارجي** (من اليسار لليمين): الغلاف 100 مم | الظهر/التواصل 100 مم | اللسان الداخلي «قصة نجاح» 97 مم  
**الوجه الداخلي** (يُقرأ من اليمين): نظرة عامة على القطاع 100 مم ← الطارئة والموسمية 100 مم ← التمكين الاقتصادي 97 مم

اللوحة الأضيق (97 مم) هي اللسان الذي ينطوي للداخل، والطيات عند 100/200 مم (خارجي) و 97/197 مم (داخلي).

## التعديل وإعادة التوليد
المصدر `brochure.html` (ألوان الهوية في `:root`). بعد التعديل:
```bash
node build.js            # يعيد توليد ملفات output/
```
الخط المستخدم Tajawal (بديل مجاني قريب من DIN Next / Neo Sans Arabic المستخدمَين في التقرير).
